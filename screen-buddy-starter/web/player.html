How a buddy is made

  1. Record. A few seconds of vertical video, head to below the knee, held still.
  2. Cut out. The person is separated from the background in every frame, at 10 frames a second.
  3. Normalise. Every frame gets the same size and the same footing, so moves never pop when they switch.
  4. Pack. Each move becomes one small transparent WebP strip. A whole buddy is about 1 to 1.5 MB.

The Studio that does steps 1 to 4 inside the app is planned. The sample buddies below were made with the same steps by script.

Make your own

A buddy is a .zip with a manifest, a face picture and one WebP strip per move. The same file works in the Android app.

Samples to download

    What goes in the zip 
    manifest.json     describes the buddy
face.webp         96×96 picture for the picker
<move>.webp       one strip per move, frames side by side

{
  "id": "my-buddy", "name": "My Buddy", "author": "Me", "version": 1,
  "cw": 240, "ch": 366, "fps": 10,
  "stand": ["groove", 0],      // the frame it rests on
  "scroll": "groove",          // the move that follows scrolling and dragging
  "poses": ["wave", "dance"],  // moves a tap can start
  "face": "face.webp",
  "clips": { "groove": { "n": 20, "src": "groove.webp" } }
}

    cw and ch are the size of one frame in pixels; each strip is n × cw wide and ch tall. File names are letters, numbers, - and _, ending in .webp.
